## 🚀 Featured Projects

### 🔎 Reunited: AI-Assisted Lost & Found Management System
*Capstone project · in development · PHP, MySQL, JavaScript*
A digital lost-and-found system for PUP Parañaque. It has six modules: authentication, lost item reporting, found item reporting, search & matching, claim & verification, and an admin dashboard. Matching uses text embeddings and cosine similarity to suggest lost/found pairs, and an admin approves each match and claim.
*Repository to be published after capstone defense.*

### 🏛️ Barangay Sto. Niño Budget Tracker System
*Full-stack · deployed · FastAPI, React/Vite, PostgreSQL*
A budget tracking system for Barangay Sto. Niño, Parañaque City. It includes AI anomaly detection (Z-score based), blockchain logging of records, and email-based password reset. The frontend is on Vercel and the backend is on Railway.
[Repository](https://github.com/renzeusss2/barangay-sto-nino-budget-tracker-system)

### 🌐 PublicBidPH
*Prototype · Stellar Soroban testnet · React/Vite, Soroban*
A decentralized public bidding platform for the Philippines, with Freighter wallet integration and Soroban smart contracts.
[Repository](https://github.com/renzeusss2/PublicBidPH)

### 🎓 StudyLend
*Hackathon project · Stellar Soroban testnet · React, Vite, TypeScript, Rust*
A paluwagan-inspired student microloan dApp. It has a full frontend plus a Soroban smart contract with USDC trustline setup.
[Repository](https://github.com/renzeusss2/StudyLend)
